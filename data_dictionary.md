# Data Dictionary - Superstore Sales

Dataset: 5000 rows, 2023-2024 Sales Data

| Column | Meaning | Example |
| :--- | :--- | :--- |
| Order ID | Order unique number | CA-2023-152156 |
| Sales | Total sales amount ($) | 261.96 |
| Profit | Profit earned ($) | 41.91 |
| Discount | Discount % given | 0.2 = 20% |
| Region | US Region | West, East, Central, South |
| Category | Product category | Furniture, Office Supplies, Technology |
| Sub-Category | Product type | Chairs, Phones, Tables |

Notes:
- Profit = Sales - Cost
- Discount > 0.25 leads to loss (my finding)
